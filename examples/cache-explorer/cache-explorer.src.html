How these numbers were made. Each request was rendered with apply_chat_template for Qwen/Qwen2.5-0.5B-Instruct and tokenized. "Reused" is the exact shared prefix in tokens: the most any prefix cache could keep.

    
Real caches keep a little less. vLLM's automatic prefix caching reuses whole blocks (16 tokens by default), shown in the third number. Anthropic's prompt caching reuses up to a cache_control breakpoint you set, with a minimum length, and documents the order as tools, then system, then messages. Qwen puts tools inside the system turn, after your system text. In both, the tools come before every message.
