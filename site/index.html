One module

Every module runs the same loop.

Each stage has its own reference file the agent re-reads before running it, and every check feeds the review log that brings ideas back as warm-ups.

  1. Warm-up

    What's due comes first: ideas from earlier modules, scheduled to return just before you'd forget them.

  2. Spot

    Each module is anchored in something you already do. The tutor starts from your own work.

  3. Probe

    It starts with high-level questions and walks down until it finds the edge of what you know.

  4. Map

    What you hold is marked and skipped. The steps left form a dependency graph to the module's goal.

  5. Steps

    Predict, try, check. At most one prediction and one check per step. A missed check gets repaired before anything builds on it.

  6. Close

    Break it, Plug back and Explain back, graded strictly, then the map redrawn from memory. A module isn't done without all three.

The module map

Your gaps, drawn as a map.

Two to four probing questions find the edge of what you know. What you hold is marked and skipped; the steps left lead to the module's goal, and each one closes only when its check passes.

  1. Probe

    Two answers come back solid. Those ideas are already yours, so they're marked as held.

  2. Map v1

    The steps left are drawn as a dependency graph, ending at the module's goal.

  3. Walk it

    Each step closes only when its check passes. The map shows where you are.

  4. Redraw it

    At the close, before seeing it again, you redraw the map from memory. Each step you miss or misplace is logged for review.

Confidence

Is "Certain" actually right?

Confidence is recorded with every answer, because a confident miss is the most useful thing a question can find. Those are the beliefs that quietly break your work. They're named, traced, repaired and retested later.

The recap page charts how often you're right at each confidence level, and how that's changing. Example numbers below.

Spaced review

Back just before you'd forget.

Every check is logged and scheduled with FSRS, so ideas come back just before you'd forget them. Ask "What's due?" or "Quiz me" and earlier modules return as warm-ups.

Grounding

Sourced, not remembered.

A model's memory is stale and unlabelled. Before planning, a separate agent finds the authoritative sources. Before each module, every claim it rests on is checked against them, with a quote and a date. What can't be supported isn't taught as fact, and your own result beats any source.

From a test topic on Python concurrency: claims checked before a module.
