# Sources

The learner's own material (`S1`, `S2`): a textbook, course notes, a syllabus, slides, a reading list, a past exam, a manual, a score. Drop files here, or note where they live (a library book, a shelf at home, a URL).

Sources the tutor found while researching (`R1`, `R2`), each with its tier: 1 primary (official docs, the statute, the standard, the original paper), 2 established secondary (a current textbook, a review), 3 leads only.

The tutor reads them, indexes them below, cites them in teaching (`S1 §4.2`, `S2 p. 42`) and checks facts against them. When a source disagrees with standard usage or a better source, the tutor says so; it never quietly teaches past it.
